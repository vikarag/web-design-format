# Minimal Design Format

## Fonts
- Arial (primary)
- Vazirmatn (Persian/Arabic)
- Noto Sans (other scripts)

## Colors
- White: #ffffff (background)
- Black: #000000 (text, borders)
- #e9e9e9 (buttons, boxes, hover states)

## Design Rules
- 0.5rem rounded corners on divs
- Simple square shapes
- Minimal CSS
- Sharp edges on all elements except divs

## Files
- style.css - Base styles
- index.html - Sample page
- format.html - Single-file version

## Usage
Include the CSS file and use the provided classes:
- .btn - Button style
- .box - Box with #e9e9e9 background
- .grid - Responsive grid layout
- .rtl - Right-to-left text direction
